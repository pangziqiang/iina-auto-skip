# OSD 可视化跳过设定器 — 设计文档

## 概述

为自动化跳过插件增加可视化进度条拖拽设定方式，取代/辅助手动输入时间。用户可直接在视频画面上拖拽手柄设定片头片尾跳过位置，拖拽时实时预览视频位置。

## 架构

### 新增文件

| 文件 | 角色 |
|------|------|
| `src/overlay.html` | OSD 覆盖层 HTML |
| `src/overlay.js` | 拖拽交互、消息通信 |
| `src/overlay.css` | 覆盖层样式 |

### 修改文件

| 文件 | 变更 |
|------|------|
| `src/index.js` | 新增 overlay 管理、消息代理 |
| `src/sidebar.html` | 新增"可视化设置"按钮 |
| `src/sidebar.js` | 新增按钮事件 |

### 通信链路

```
overlay.js ←→ index.js ←→ mpv
     ↑              ↑
  postMessage    postMessage
```

## 操作流程

1. 进入调整模式：侧边栏"可视化设置"按钮 或 快捷键 S（可配置）
2. OSD 覆盖层浮现，包含进度条和双手柄
3. 拖拽手柄 → 视频实时 seek 预览
4. 点"保存"→ 持久化配置 → 关闭覆盖层
5. 点"取消"/ESC/快捷键 → 关闭覆盖层，不保存

## OSD 界面

### 布局
- 覆盖层位于视频底部，水平居中，宽度为视频 80%
- 背景从透明向上渐变至 rgba(0,0,0,0.85)
- 进度条 + 双手柄 + 时间标签 + 底部操作栏

### 配色
- 沿用 IINA 蓝色主题 (`#0a84ff` / `#007aff`，跟随暗亮模式)
- 文字白色，次要文字灰色

### 空闲淡化
- 3 秒无操作 → 半透明淡化（只留手柄和时间标签）
- 8 秒无操作 → 完全隐藏（仅提示"鼠标移入即可调整"）
- 鼠标移入覆盖区 → 立即恢复完整显示

## 手柄交互

### 拖动行为
- 按下手柄：视频暂停（定格）
- 水平拖动：每 100ms 节流向 mpv 发送 seek
- 松开手柄：视频恢复播放
- 超出边界自动卡在 0 / duration

### 互锁
- 左手柄（片头结束）≤ 右手柄（片尾开始）- 1 秒
- 右手柄（片尾开始）≥ 左手柄（片头结束）+ 1 秒

### 视觉反馈
- 拖拽时手柄下方浮现大号时间标签
- 左右手柄之间轨道高亮蓝色
- 松开后时间标签保留

## 数据流

### overlay 打开
```
用户操作 → index.js 读取 config → overlay.showFile("src/overlay.html")
→ overlay.js 请求 time-pos → 渲染手柄位置
```

### 拖拽预览
```
拖动手柄 → overlay.js 计算时间
→ iina.postMessage("overlay-seek", time)
→ index.js → mpv.setProperty("time-pos", time)
→ 视频跳转
```

### 保存
```
点保存 → overlay.js → iina.postMessage("overlay-save", {intro, outro})
→ index.js saveConfig() → overlay.hide()
```

## 边界处理

| 场景 | 行为 |
|------|------|
| 无文件播放 | 显示"暂无视频"，不可拖动 |
| 视频 < 10秒 | 自动禁用，提示"视频过短" |
| 片头 + 片尾重叠 | 左右手柄互锁，最小间隔 1 秒 |
| 关闭时视频播放中 | 恢复原有播放状态 |
| 侧边栏 + overlay 同时存在 | 侧边栏实时同步显示时间值 |
| 快捷键冲突 | 复用现有 keybind 配置 |

## 非功能性需求
- 拖拽节流 100ms，避免压垮 mpv
- 覆盖层不阻塞视频原有播放控制
- 手柄精确到秒（整数）
- 日志系统不变，跳过事件由 index.js 统一记录
