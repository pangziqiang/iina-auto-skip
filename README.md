# Auto Skip - IINA Plugin v1.2.0

自动跳过片头片尾的 IINA 插件。支持独立窗口设置和 OSD 可视化拖拽两种方式。

## 功能

- **跳过片头**：设置开头要跳过的秒数，播放时自动快进
- **跳过片尾**：设置结尾前停止的秒数，播放时自动跳至末尾
- **可视化设定**：在视频上拖拽手柄设定片头片尾，实时预览
- **独立窗口**：设置面板在独立窗口中，不遮挡视频画面
- **中/英文**：跟随系统语言自动切换
- **快捷键**：支持自定义快捷键

## 使用

- **菜单**：`插件` → `自动跳过`
- **设置窗口快捷键**：默认 <kbd>S</kbd>
- **可视化设定快捷键**：默认 <kbd>A</kbd>
- **偏好设置**：`插件` → `自动跳过` → `偏好设置`，可自定义快捷键

### 可视化设定

1. 按 <kbd>A</kbd> 打开 OSD 覆盖层
2. 视频暂停，底部出现进度条
3. 拖拽 **蓝色 I（片头）** 和 **橙色 O（片尾）** 手柄
4. 点击进度条可快速跳转手柄位置
5. 保存并关闭 / 保存（保持打开）/ 取消

## 安装

**要求**：IINA 1.4.0 或更高版本（需要 `video-overlay` 权限支持）。

在 IINA 设置 → 插件中安装 `.iinaplgz` 文件，或双击安装。
