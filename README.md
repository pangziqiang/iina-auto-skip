# Auto Skip - IINA Plugin

自动跳过片头片尾的 IINA 侧边栏插件。设置秒数后，播放时自动跳过指定区间。

## 功能

- **跳过片头**：设置开头要跳过的秒数，播放时自动快进
- **跳过片尾**：设置结尾前停止的秒数，播放时自动跳至末尾
- **快捷开关**：侧边栏一键启用/禁用
- **快捷键**：支持自定义快捷键切换侧边栏

## 使用

- **菜单**：`插件` → `自动跳过`
- **快捷键**：<kbd>⌘</kbd> + <kbd>G</kbd>

## 安装

**要求**：IINA 1.4.0 或更高版本。

在 IINA 设置 → 插件中安装 `.iinaplgz` 文件。
